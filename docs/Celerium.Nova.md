# Celerium.Nova Module

## Description

Celerium.Nova is a standalone PowerShell module for Windows PowerShell 5.1 & PowerShell 7+. The New-clNovaHtml* functions turn any PowerShell object into a modern, offline friendly HTML report that other functions & scripts can use.

## Celerium.Nova

### [ConvertTo-clNovaHtmlDataUri](site/Internal/ConvertTo-clNovaHtmlDataUri.md)

Converts an image file to a data uri that can be embedded in an HTML page

### [ConvertTo-clNovaHtmlEncoded](site/Internal/ConvertTo-clNovaHtmlEncoded.md)

Encodes text so that it can safely be placed in HTML

### [Expand-clNovaHtmlTemplate](site/Internal/Expand-clNovaHtmlTemplate.md)

Replaces the {{Name}} tokens of an HTML template with values

### [Get-clNovaCardLayout](site/Internal/Get-clNovaCardLayout.md)

Calculates how many summary cards are placed in each row

### [Get-clNovaHtmlIcon](site/Internal/Get-clNovaHtmlIcon.md)

Gets an inline SVG icon for an HTML report

### [Get-clNovaHtmlResource](site/Internal/Get-clNovaHtmlResource.md)

Gets the content of a file used to build an HTML report

### [Get-clNovaResourcePath](site/Internal/Get-clNovaResourcePath.md)

Finds a resource file (template, css, js, icon, or data file) of the module

### [New-clNovaHtmlReport](site/HtmlReport/New-clNovaHtmlReport.md)

Creates a modern, mobile friendly HTML report from PowerShell objects

### [New-clNovaHtmlSummaryCard](site/HtmlReport/New-clNovaHtmlSummaryCard.md)

Creates the HTML of one summary card

### [New-clNovaHtmlSummaryCardSet](site/HtmlReport/New-clNovaHtmlSummaryCardSet.md)

Creates the HTML of a group of summary cards that are laid out in evenly filled rows

### [New-clNovaHtmlTable](site/HtmlReport/New-clNovaHtmlTable.md)

Creates the HTML of a sortable, searchable table card from PowerShell objects
