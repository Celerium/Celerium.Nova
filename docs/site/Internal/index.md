## Internal - help & documentation

{: .highlight }
Use `Get-Help <function> -Full` for the help of a function. The examples of the project are in the [examples folder](https://github.com/Celerium/Celerium.Nova/tree/main/examples)

| **Function** | **Synopsis** |
|--------------|--------------|
| [ConvertTo-clNovaHtmlDataUri](ConvertTo-clNovaHtmlDataUri.html) | Converts an image file to a data uri that can be embedded in an HTML page |
| [ConvertTo-clNovaHtmlEncoded](ConvertTo-clNovaHtmlEncoded.html) | Encodes text so that it can safely be placed in HTML |
| [Expand-clNovaHtmlTemplate](Expand-clNovaHtmlTemplate.html) | Replaces the {{Name}} tokens of an HTML template with values |
| [Get-clNovaCardLayout](Get-clNovaCardLayout.html) | Calculates how many summary cards are placed in each row |
| [Get-clNovaHtmlIcon](Get-clNovaHtmlIcon.html) | Gets an inline SVG icon for an HTML report |
| [Get-clNovaHtmlResource](Get-clNovaHtmlResource.html) | Gets the content of a file used to build an HTML report |
| [Get-clNovaResourcePath](Get-clNovaResourcePath.html) | Finds a resource file (template, css, js, icon, or data file) of the module |

Have a look around and if you would like to contribute please read over the [Contributing guide](https://github.com/Celerium/Celerium.Nova/blob/main/.github/CONTRIBUTING.md)
