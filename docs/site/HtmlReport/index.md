## HtmlReport - help & documentation

{: .highlight }
Use `Get-Help <function> -Full` for the help of a function. The examples of the project are in the [examples folder](https://github.com/Celerium/Celerium.Nova/tree/main/examples)

| **Function** | **Synopsis** |
|--------------|--------------|
| [New-clNovaHtmlReport](New-clNovaHtmlReport.html) | Creates a modern, mobile friendly HTML report from PowerShell objects |
| [New-clNovaHtmlSummaryCard](New-clNovaHtmlSummaryCard.html) | Creates the HTML of one summary card |
| [New-clNovaHtmlSummaryCardSet](New-clNovaHtmlSummaryCardSet.html) | Creates the HTML of a group of summary cards that are laid out in evenly filled rows |
| [New-clNovaHtmlTable](New-clNovaHtmlTable.html) | Creates the HTML of a sortable, searchable table card from PowerShell objects |

Have a look around and if you would like to contribute please read over the [Contributing guide](https://github.com/Celerium/Celerium.Nova/blob/main/.github/CONTRIBUTING.md)
